APPLY THE IDEA

Worked example

A cart total is derived from cart items and discount; a computed value stays consistent without an effect copying the total into mutable state.

  1. Keep signal state minimal and derive values with computed.
  2. Use update for transitions based on the previous value.
  3. Use effect cleanup for timers, listeners, or other owned resources.

CODE OR QUERY

Try it

readonly items = signal<Item[]>([]);
readonly total = computed(() =>
  this.items().reduce((sum, item) => sum + item.price, 0)
);

add(item: Item): void {
  this.items.update(items => [...items, item]);
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Synchronous reads and derived values are straightforward
  • Template consumers receive fine-grained notifications

Limitations

  • Effects can form cycles or leak external resources
  • Signals alone do not provide time-based stream operators

DECISION GUIDE

When to use it

Use: Use signals for synchronous state and computed for pure derivation; use effects only for imperative boundaries.

Avoid: Avoid duplicating derived state or starting unmanaged async work inside effects.

COMMON MISTAKES

Watch out

  • Creating an effect that writes a mirror of another signal.
  • Assuming effects run synchronously in every context or can replace RxJS cancellation.
  • Mutating arrays/objects in place without setting an updated value.

BEST PRACTICES

In practice

  • Keep effects at integration boundaries, not in the middle of ordinary data flow.
  • Avoid side effects in computed functions.
  • Use interop APIs deliberately when converting between signals and observables.

SENIOR-LEVEL SCENARIO

Production thinking

A filter panel maintains local selections and a derived result count. Signals model selections and computed derives the count; an Observable remains responsible for debounced server search.

SUMMARY

In one minute

A signal is a getter/setter-style reactive value: reading it tracks a dependency in a reactive context, while set/update changes its value and notifies consumers. computed creates a lazy, memoized derived signal; effect runs imperative work when tracked dependencies change. Signals make local UI state and derived state explicit and integrate with Angular rendering. They do not automatically make arbitrary asynchronous work cancellable, nor are effects a replacement for every stream transformation.
