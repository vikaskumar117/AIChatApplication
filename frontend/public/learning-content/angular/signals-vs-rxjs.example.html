APPLY THE IDEA

Worked example

A search page uses RxJS debounceTime and switchMap for requests, then exposes the latest result as a signal for synchronous template derivations.

  1. Keep RxJS operators for debounce, switchMap, retries, and multi-event composition.
  2. Use computed for synchronous derivation from signal state.
  3. Choose toSignal initial values or requireSync based on source guarantees.

CODE OR QUERY

Try it

readonly results = toSignal(
  this.query$.pipe(
    debounceTime(250),
    switchMap(query => this.api.search(query))
  ),
  { initialValue: [] as Result[] }
);

TRADE-OFFS

Benefits and limitations

Benefits

  • Each abstraction is strong in its own domain
  • Interop allows incremental architecture

Limitations

  • Conversions can obscure subscription lifetime or initial state
  • Using only one abstraction creates awkward workarounds

DECISION GUIDE

When to use it

Use: Use signals for current state and RxJS for temporal/asynchronous composition; interoperate at component/service boundaries.

Avoid: Avoid treating a signal as a multi-value stream or an Observable as a synchronous state container.

COMMON MISTAKES

Watch out

  • Converting every Observable into a signal even when stream operators are still needed.
  • Creating repeated conversions that create duplicate subscriptions.
  • Ignoring error and initial-value behavior at the interop boundary.

BEST PRACTICES

In practice

  • Make subscription ownership and source sharing explicit.
  • Use toObservable only when a consumer needs stream composition.
  • Keep each value’s canonical source of truth singular.

SENIOR-LEVEL SCENARIO

Production thinking

A screen needs cancellable typeahead plus synchronous computed sorting. Keep the network timing pipeline in RxJS, bridge its latest result with toSignal, and derive local sorting with computed.

SUMMARY

In one minute

A signal always represents a current value readable synchronously. An Observable represents zero or more future emissions, with subscription, completion, error, and teardown semantics; it may be cold or hot. Use signals for component/application state and pure derived values. Use RxJS for HTTP pipelines, user event timing, cancellation, retries, and combining streams; bridge at a clear boundary instead of converting reflexively.
