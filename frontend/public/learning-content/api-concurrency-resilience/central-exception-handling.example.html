CODE OR QUERY

Try it

builder.Services.AddProblemDetails();
builder.Services.AddExceptionHandler<ApiExceptionHandler>();
app.UseExceptionHandler();

internal sealed class ApiExceptionHandler(ILogger<ApiExceptionHandler> logger)
    : IExceptionHandler
{
    public ValueTask<bool> TryHandleAsync(
        HttpContext context, Exception exception, CancellationToken ct)
    {
        logger.LogError(exception, "Unhandled request failure {TraceId}",
            context.TraceIdentifier);
        return ValueTask.FromResult(false); // Leave generic handling to configured pipeline.
    }
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Consistent error shape and centralized telemetry
  • Keeps endpoint code focused on expected outcomes

Limitations

  • Incorrect mapping can hide faults or mislead clients
  • Handled exceptions need explicit logging and observability

DECISION GUIDE

When to use it

Use: Use global middleware or IExceptionHandler for unexpected failures and narrowly mapped known domain exceptions.

Avoid: Avoid catch-all success responses, exception-driven normal control flow, and public stack traces.

COMMON MISTAKES

Watch out

  • Returning true for every exception without logging it.
  • Mapping every exception to 400 or including its message in the response.

BEST PRACTICES

In practice

  • Attach trace correlation and alert on unexpected 5xx rates.
  • Test known mapping, unknown fallback, response-started behavior, and disclosure.

INTERVIEW PRACTICE

Common questions

  1. Why must exception middleware be early?
  2. When should a handler return false?
  3. How should a known concurrency exception differ from an unknown exception?

SENIOR-LEVEL SCENARIO

Production thinking

A custom handler suppresses all diagnostics while returning 500; ensure handled exceptions are logged and measured, and let unknown failures reach the generic safe fallback.

SUMMARY

In one minute

Centralized exception handling turns unhandled failures into consistent, safe API responses while preserving operational diagnostics.
