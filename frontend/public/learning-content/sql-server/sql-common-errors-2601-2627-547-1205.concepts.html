THE IDEA

What is it?

SQL Server error numbers identify a failure category, but the constraint, statement, transaction state, and surrounding context explain the root cause. 2601 and 2627 indicate unique-key violations; 547 indicates a CHECK or FOREIGN KEY constraint conflict; 1205 means the transaction was selected as a deadlock victim.

WHY IT MATTERS

What problem does it solve?

Fixing the invariant or concurrency behavior is more reliable than memorizing numbers or retrying every database exception.

UNDER THE HOOD

How does it work?

Capture structured exception number, constraint/index, operation, correlation ID, and safe parameter context. For 2601/2627, prevent conflicting writes or handle idempotent duplicate requests; for 547, correct parent/child order or business references; for 1205, inspect deadlock graph and retry only a safe whole transaction.

KEY TAKEAWAYS

Remember

  • 2601/2627 are uniqueness conflicts; the constraint is protecting an invariant.
  • 547 is a constraint conflict, commonly FK or CHECK; fix relationship or input.
  • 1205 reports a deadlock victim, not a generic connection failure.
  • Error number plus constraint, operation, transaction state, and correlation gives actionable diagnosis.
