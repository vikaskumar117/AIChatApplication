APPLY THE IDEA

Worked example

Return employees whose salary is strictly greater than their department’s average non-NULL salary.

  1. Define which employees contribute to the average.
  2. Calculate AVG over each DepartmentId partition.
  3. Keep the employee-level rows and filter in the outer query.
  4. Validate NULL and decimal precision behavior.

CODE OR QUERY

Try it

WITH scored AS (
  SELECT e.EmployeeId, e.Name, e.DepartmentId, e.Salary,
         AVG(CAST(e.Salary AS decimal(19, 4))) OVER (
           PARTITION BY e.DepartmentId
         ) AS DepartmentAverage
  FROM dbo.Employee AS e
)
SELECT EmployeeId, Name, DepartmentId, Salary, DepartmentAverage
FROM scored
WHERE Salary > DepartmentAverage
ORDER BY DepartmentId, Salary DESC;

TRADE-OFFS

Benefits and limitations

Benefits

  • Window aggregate avoids a separate self-join and preserves employee detail.
  • The comparison uses each department’s own cohort.

Limitations

  • The query must read enough rows to calculate averages.
  • NULL salaries are ignored by AVG; a department with all NULL salaries has no qualifying comparisons.

DECISION GUIDE

When to use it

Use: Use a window aggregate when both employee details and a department statistic are required.

Avoid: Do not compare to a company-wide AVG or silently coalesce an undefined all-NULL group average to zero.

COMMON MISTAKES

Watch out

  • Comparing against the overall company average.
  • Using integer arithmetic or unintended salary conversion precision.
  • Forgetting that filtering employees before the window changes the cohort.

BEST PRACTICES

In practice

  • Make population eligibility and NULL handling explicit.
  • Use an appropriate decimal type for the aggregate.
  • Test small departments and all-NULL salary groups.

INTERVIEW PRACTICE

Common questions

  1. Why use PARTITION BY here?
  2. How does AVG treat NULL salaries?
  3. Why filter the computed average in an outer query?

SENIOR-LEVEL SCENARIO

Production thinking

A compensation audit flags employees above their group mean. Confirm whether salary components and inactive employees belong in the cohort, then validate the group and NULL policy with HR before reporting.

SUMMARY

In one minute

A per-department comparison evaluates each employee salary against an aggregate calculated for that employee’s department. A single overall average answers a different question. A windowed average keeps employee detail while computing a group-level benchmark.
