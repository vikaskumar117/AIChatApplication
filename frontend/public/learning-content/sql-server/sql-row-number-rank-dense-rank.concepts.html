THE IDEA

What is it?

These window ranking functions assign positions within an ordered partition. ROW_NUMBER assigns a unique sequence; RANK gives ties the same rank and leaves gaps; DENSE_RANK gives ties the same rank without gaps.

WHY IT MATTERS

What problem does it solve?

The ranking function determines how ties affect top-N boundaries and whether a query returns a fixed row count or a fixed number of rank/value levels.

UNDER THE HOOD

How does it work?

Use OVER(PARTITION BY group ORDER BY score) to define scope and order. ROW_NUMBER ordering should include a unique key for repeatability. RANK and DENSE_RANK preserve equal ordering values as ties.

KEY TAKEAWAYS

Remember

  • ROW_NUMBER is a row sequence; RANK is competition position; DENSE_RANK is distinct-value position.
  • Ties make rank <= N potentially return more than N rows.
  • A unique order is needed for repeatable ROW_NUMBER assignments.
  • Partitioning restarts the ranking independently for each group.
