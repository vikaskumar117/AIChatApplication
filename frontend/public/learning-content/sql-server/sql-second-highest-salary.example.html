APPLY THE IDEA

Worked example

Return the second distinct salary value and all employees paid that amount.

  1. Exclude NULL salaries according to the stated rule.
  2. Assign a dense rank over all employees ordered by salary descending.
  3. Filter rank 2 outside the ranking query.
  4. Return all ties at the second distinct amount.

CODE OR QUERY

Try it

WITH ranked AS (
  SELECT EmployeeId, Name, Salary,
         DENSE_RANK() OVER (ORDER BY Salary DESC) AS salary_rank
  FROM dbo.Employee
  WHERE Salary IS NOT NULL
)
SELECT EmployeeId, Name, Salary
FROM ranked
WHERE salary_rank = 2;

TRADE-OFFS

Benefits and limitations

Benefits

  • DENSE_RANK states distinct-value semantics and preserves all employees tied at the amount.
  • The query naturally returns no rows when fewer than two distinct non-NULL amounts exist.

Limitations

  • Ranking may sort the candidate set.
  • Different business meanings require different ranking semantics.

DECISION GUIDE

When to use it

Use: Use DENSE_RANK when asking for the second-highest distinct salary and the employees receiving it.

Avoid: Avoid MAX(MAX(...)) when NULL, no rows, or tie behavior is unclear; avoid ROW_NUMBER without deterministic ordering.

COMMON MISTAKES

Watch out

  • Using ROW_NUMBER and arbitrarily selecting among tied salaries.
  • Using RANK = 2 and overlooking rank gaps.
  • Ignoring NULL and empty-table behavior.

BEST PRACTICES

In practice

  • Document whether the output is a value or employee row.
  • Test tied maximum, tied second, NULL, and fewer-than-two-value cases.
  • Use DENSE_RANK for distinct ordinal values.

INTERVIEW PRACTICE

Common questions

  1. Why does DENSE_RANK differ from ROW_NUMBER with ties?
  2. What should the query return when fewer than two distinct salaries exist?
  3. How can a unique tie-breaker define the second employee row?

SENIOR-LEVEL SCENARIO

Production thinking

An HR API is asked for “the second highest salary.” Clarify whether the API returns a salary amount or a person position, define tie behavior, and test zero, one, tied-highest, and tied-second cases.

SUMMARY

In one minute

Second-highest can mean the second distinct salary value, or the employee row in second place. Those meanings differ when salaries tie. Explicitly defining the result avoids returning an arbitrary employee or mistakenly treating two employees tied for the highest pay as first and second.
