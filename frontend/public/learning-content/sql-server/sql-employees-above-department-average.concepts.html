THE IDEA

What is it?

A per-department comparison evaluates each employee salary against an aggregate calculated for that employee’s department.

WHY IT MATTERS

What problem does it solve?

A single overall average answers a different question. A windowed average keeps employee detail while computing a group-level benchmark.

UNDER THE HOOD

How does it work?

AVG(Salary) OVER (PARTITION BY DepartmentId) attaches an average to each employee row. Filter in an outer query because the window alias is not available in that query block’s WHERE.

KEY TAKEAWAYS

Remember

  • Window aggregates retain row detail while calculating group statistics.
  • PARTITION BY prevents the average from becoming global.
  • AVG ignores NULL inputs; all-NULL groups produce NULL.
  • Filter a window alias in an outer query block.
