THE IDEA

What is it?

The maximum salary per department can be returned as a value, or with the employee row or rows that achieve it.

WHY IT MATTERS

What problem does it solve?

A grouped MAX returns only the amount; reporting the employee requires a join-back or a ranking method. Ties must be treated intentionally.

UNDER THE HOOD

How does it work?

Use MAX with GROUP BY for amounts. Use DENSE_RANK or a join on department plus maximum when all ties should appear; use ROW_NUMBER with deterministic ordering for one chosen winner.

KEY TAKEAWAYS

Remember

  • GROUP BY MAX returns a value, not its associated employee.
  • Rank 1 preserves all equal maximum rows.
  • Join-back must include the grouping key.
  • Define behavior for NULL-only departments.
