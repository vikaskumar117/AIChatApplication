APPLY THE IDEA

Worked example

Return every employee tied for the highest non-NULL salary in their department.

  1. Filter NULL salaries if those do not represent a pay amount.
  2. Rank rows descending within each department.
  3. Select rank 1 and retain all ties.
  4. If only the maximum amount is needed, use GROUP BY DepartmentId with MAX(Salary).

CODE OR QUERY

Try it

WITH ranked AS (
  SELECT EmployeeId, Name, DepartmentId, Salary,
         DENSE_RANK() OVER (
           PARTITION BY DepartmentId ORDER BY Salary DESC
         ) AS salary_rank
  FROM dbo.Employee
  WHERE Salary IS NOT NULL
)
SELECT EmployeeId, Name, DepartmentId, Salary
FROM ranked
WHERE salary_rank = 1
ORDER BY DepartmentId, EmployeeId;

TRADE-OFFS

Benefits and limitations

Benefits

  • Window ranking preserves employee details and all top ties.
  • The tie policy is visible and testable.

Limitations

  • Ranking may sort data; grouped aggregate plus join can also require additional work.
  • Departments with no non-NULL salary have no qualifying employee.

DECISION GUIDE

When to use it

Use: Use DENSE_RANK = 1 when the answer should include every employee tied at the department maximum.

Avoid: Avoid joining only by salary; include the department key or employees from other departments may match.

COMMON MISTAKES

Watch out

  • Selecting an unrelated employee name alongside MAX without a valid grouping rule.
  • Joining max salary back on salary only and mixing departments.
  • Using ROW_NUMBER when all ties are required.

BEST PRACTICES

In practice

  • Specify whether ties are all returned or one is selected.
  • Use a unique tie-breaker for one-winner requirements.
  • Test NULL-only and tied-maximum groups.

INTERVIEW PRACTICE

Common questions

  1. Why does GROUP BY MAX not return the employee name?
  2. How do you include all employees tied for maximum?
  3. What columns are needed in an aggregate join-back?

SENIOR-LEVEL SCENARIO

Production thinking

A dashboard needs the top-paid employee in each department. Product clarifies all ties should appear; implement rank 1 and test departments with no salary and multiple maximum-paid people.

SUMMARY

In one minute

The maximum salary per department can be returned as a value, or with the employee row or rows that achieve it. A grouped MAX returns only the amount; reporting the employee requires a join-back or a ranking method. Ties must be treated intentionally.
