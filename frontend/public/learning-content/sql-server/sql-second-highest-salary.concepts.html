THE IDEA

What is it?

Second-highest can mean the second distinct salary value, or the employee row in second place. Those meanings differ when salaries tie.

WHY IT MATTERS

What problem does it solve?

Explicitly defining the result avoids returning an arbitrary employee or mistakenly treating two employees tied for the highest pay as first and second.

UNDER THE HOOD

How does it work?

For the second distinct amount, use DENSE_RANK over salary DESC and filter rank 2. For exactly the second row, use ROW_NUMBER with a stable unique tie-breaker. MAX below MAX is an alternative for one distinct amount but handles NULL and empty input deliberately.

KEY TAKEAWAYS

Remember

  • “Second-highest salary” is ambiguous until tie semantics are defined.
  • DENSE_RANK returns the second distinct value.
  • ROW_NUMBER returns a row position and needs deterministic ordering.
  • No rank 2 means no result, not an invented zero.
