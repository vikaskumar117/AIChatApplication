THE IDEA

What is it?

Top-N-per-group returns a limited or ranked set of employees independently within each department. A window function computes a rank without collapsing employee rows.

WHY IT MATTERS

What problem does it solve?

A single global TOP (3) returns only three employees overall. Partitioning provides a scalable expression of the per-department requirement and allows the result to retain employee details.

UNDER THE HOOD

How does it work?

Use ROW_NUMBER when exactly three rows per department are required and ties need a deterministic tie-breaker. Use RANK or DENSE_RANK when salary ties should share a position; rank <= 3 can return more than three employees. Define the policy explicitly.

KEY TAKEAWAYS

Remember

  • Partitioning restarts rank per department.
  • DENSE_RANK <= 3 means three distinct salary values, not three employee rows.
  • Window calculations are filtered in an outer query or CTE.
  • Use actual plan data to assess sorting and indexing.
