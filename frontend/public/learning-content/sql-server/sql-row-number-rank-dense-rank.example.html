APPLY THE IDEA

Worked example

For scores 100, 90, 90, 80 the functions return row numbers 1,2,3,4; ranks 1,2,2,4; dense ranks 1,2,2,3.

  1. Choose whether ties should share a rank.
  2. Define partition and ranking columns.
  3. Include a unique tie-breaker only when individual row order should be unique.
  4. Filter using the selected function’s semantics.

CODE OR QUERY

Try it

SELECT EmployeeId, Salary,
       ROW_NUMBER() OVER (ORDER BY Salary DESC, EmployeeId) AS row_num,
       RANK()       OVER (ORDER BY Salary DESC) AS salary_rank,
       DENSE_RANK() OVER (ORDER BY Salary DESC) AS salary_dense_rank
FROM dbo.Employee
ORDER BY Salary DESC, EmployeeId;

TRADE-OFFS

Benefits and limitations

Benefits

  • Provides explicit control of row positions and tie behavior.
  • Works for pagination, leaderboards, and top-N analyses.

Limitations

  • Ordering can require substantial sorting.
  • Nondeterministic ROW_NUMBER ties can change between executions without a unique ordering.

DECISION GUIDE

When to use it

Use: Use ROW_NUMBER for a deterministic single row sequence; RANK for competition ranking; DENSE_RANK for distinct ordered values.

Avoid: Do not filter rank values before defining what ties should mean; do not expect RANK <= N to return exactly N rows.

COMMON MISTAKES

Watch out

  • Adding EmployeeId to RANK ordering when equal salaries must remain tied.
  • Expecting RANK to have no gaps after ties.
  • Assuming ROW_NUMBER is repeatable when order columns are not unique.

BEST PRACTICES

In practice

  • Test ranking functions with intentional ties and cutoff ties.
  • Document whether N means rows, places, or distinct values.
  • Use stable unique ordering when deterministic row assignment matters.

INTERVIEW PRACTICE

Common questions

  1. What ranks result for values 100, 90, 90, 80?
  2. Which function returns exactly N rows if enough rows exist?
  3. When should the ordering include a unique key?

SENIOR-LEVEL SCENARIO

Production thinking

A leaderboard shows duplicate place labels and a top-five report returns six people. Align rank semantics with product: competition places, distinct score levels, or exactly five rows, then test ties at the cutoff.

SUMMARY

In one minute

These window ranking functions assign positions within an ordered partition. ROW_NUMBER assigns a unique sequence; RANK gives ties the same rank and leaves gaps; DENSE_RANK gives ties the same rank without gaps. The ranking function determines how ties affect top-N boundaries and whether a query returns a fixed row count or a fixed number of rank/value levels.
