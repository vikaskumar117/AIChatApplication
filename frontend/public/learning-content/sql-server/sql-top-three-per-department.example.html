APPLY THE IDEA

Worked example

Return every employee whose salary is in the top three distinct salary levels in their department; ties at the cutoff are included.

  1. Select the employee detail columns.
  2. Partition by department and order by salary descending.
  3. Choose DENSE_RANK so equal salaries share a rank without gaps.
  4. Filter in an outer query because the window result is not available in the same query WHERE.

CODE OR QUERY

Try it

WITH ranked AS (
  SELECT e.EmployeeId, e.Name, e.DepartmentId, e.Salary,
         DENSE_RANK() OVER (
           PARTITION BY e.DepartmentId ORDER BY e.Salary DESC
         ) AS salary_rank
  FROM dbo.Employee AS e
)
SELECT EmployeeId, Name, DepartmentId, Salary, salary_rank
FROM ranked
WHERE salary_rank <= 3
ORDER BY DepartmentId, Salary DESC, EmployeeId;

TRADE-OFFS

Benefits and limitations

Benefits

  • Window functions preserve row details while ranking each group.
  • The rank predicate makes inclusion of salary ties explicit.

Limitations

  • Ranking may require sorting many rows and memory; spills can hurt performance.
  • Tie-inclusive ranks may return more than three employees per department.

DECISION GUIDE

When to use it

Use: Use this when the business definition is top three salary levels per department and all ties at those levels should appear.

Avoid: Do not use DENSE_RANK if the contract requires exactly three employee rows; choose ROW_NUMBER with a stable unique ordering instead.

COMMON MISTAKES

Watch out

  • Using TOP (3) globally and expecting it to reset per department.
  • Assuming ties cannot cause more than three output rows.
  • Filtering a window-function alias in the same SELECT-level WHERE.

BEST PRACTICES

In practice

  • Write down whether N means rows, rank positions, or distinct values.
  • Add a deterministic unique tie-breaker to ROW_NUMBER ordering.
  • Test departments with salary ties at both included and excluded boundaries.

INTERVIEW PRACTICE

Common questions

  1. Why is global TOP not a per-department solution?
  2. How does the tie policy affect the number of returned rows?
  3. What index key order could support this partition and order?

SENIOR-LEVEL SCENARIO

Production thinking

Compensation reporting requires everyone sharing any of the top three salary levels in each department. Confirm that ties are included, rank within department, then inspect sort and memory grant behavior on production-like volumes.

SUMMARY

In one minute

Top-N-per-group returns a limited or ranked set of employees independently within each department. A window function computes a rank without collapsing employee rows. A single global TOP (3) returns only three employees overall. Partitioning provides a scalable expression of the per-department requirement and allows the result to retain employee details.
