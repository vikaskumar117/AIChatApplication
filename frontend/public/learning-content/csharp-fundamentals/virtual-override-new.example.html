APPLY THE IDEA

Worked example

With override, a Base variable referencing a Derived object calls Derived.Run; with new, the same base variable calls Base.Run.

  1. Create a Derived instance and store it in a Base variable.
  2. Call virtual Run and observe derived implementation.
  3. Call hidden Name and observe base member due to static type.

CODE OR QUERY

Try it

class Base
{
    public virtual string Run() => "base";
    public string Name() => "base name";
}
class Derived : Base
{
    public override string Run() => "derived";
    public new string Name() => "derived name";
}

Base value = new Derived();
Console.WriteLine(value.Run());  // derived: virtual override
Console.WriteLine(value.Name()); // base name: member hidden with new

TRADE-OFFS

Benefits and limitations

Benefits

  • Override preserves polymorphic contract
  • new can intentionally separate APIs

Limitations

  • Hiding makes behavior depend on static type
  • Broad virtual surfaces constrain future changes

DECISION GUIDE

When to use it

Use: Use override when substituting a base behavior; use new only for deliberate hiding with clear reason.

Avoid: Avoid virtualizing members indiscriminately or suppressing hiding warnings blindly.

COMMON MISTAKES

Watch out

  • Adding new to silence a warning without checking behavior.
  • Assuming new overrides all base-typed calls.

BEST PRACTICES

In practice

  • Prefer override for genuine substitutability.
  • Keep base classes and virtual surface small.
  • Test behavior through public abstractions.

INTERVIEW PRACTICE

Common questions

  1. What does override require?
  2. Does new replace virtual dispatch?
  3. Why can a base reference call a different hidden member?

SENIOR-LEVEL SCENARIO

Production thinking

A framework base class gains a member with the same name as a derived API. Resolve compiler warnings consciously and test calls through both declared types before release.

SUMMARY

In one minute

virtual opens a runtime dispatch slot, override replaces it, and new hides a name according to compile-time type.
