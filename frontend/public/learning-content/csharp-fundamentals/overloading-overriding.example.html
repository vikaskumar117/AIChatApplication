APPLY THE IDEA

Worked example

Format(string) and Format(DateTime) overloads are chosen by argument type; a derived formatter override is selected when called through a base reference.

  1. Call Format with a string and inspect the chosen overload.
  2. Call Format with DateTime through a base-typed variable.
  3. Observe that the variable type does not suppress virtual override dispatch.

CODE OR QUERY

Try it

class Formatter
{
    public string Format(string value) => value.Trim();
    public virtual string Format(DateTime value) => value.ToString("O");
}
sealed class LocalFormatter : Formatter
{
    public override string Format(DateTime value) => value.ToLocalTime().ToString("O");
}

Formatter formatter = new LocalFormatter();
string text = formatter.Format(DateTime.UtcNow); // override dispatches at runtime
string trimmed = formatter.Format("  hi ");      // overload selected at compile time

TRADE-OFFS

Benefits and limitations

Benefits

  • Overloads offer ergonomic signatures
  • Overrides enable substitutable runtime behavior

Limitations

  • Ambiguous overloads can surprise
  • Overriding changes behavior for all base-typed callers

DECISION GUIDE

When to use it

Use: Use overloads for the same operation on meaningfully different inputs; use virtual dispatch for intentional extension points.

Avoid: Avoid overload sets whose implicit conversions make calls ambiguous.

COMMON MISTAKES

Watch out

  • Expecting overload selection to depend on runtime argument type.
  • Calling an override “overloading” because it shares a method name.

BEST PRACTICES

In practice

  • Keep overloads semantically consistent.
  • Use virtual members only for supported extension behavior.
  • Test through base contracts.

INTERVIEW PRACTICE

Common questions

SENIOR-LEVEL SCENARIO

Production thinking

A serialization framework has format-specific inputs and customer-specific output policy. Keep input overloads clear and make only stable extension points virtual.

SUMMARY

In one minute

Overloads vary parameter signatures and resolve statically; overrides replace inherited virtual behavior and dispatch dynamically.
