APPLY THE IDEA

Worked example

Reserve inventory, authorize payment, then confirm. If payment is declined, release the reservation; if a refund is required, record it as a new financial transaction.

  1. Persist progress and each step’s operation identity.
  2. Model timeout as an uncertain result until reconciled.
  3. Make compensation idempotent and auditable.
  4. Provide stuck-saga alerts and controlled operator recovery.

CODE OR QUERY

Try it

// Orchestrated saga outline:
await inventory.ReserveAsync(orderId, stepKey, ct);
try { await payments.AuthorizeAsync(orderId, stepKey, ct); }
catch (PaymentDeclinedException) { await inventory.ReleaseAsync(orderId, stepKey, ct); }

TRADE-OFFS

Benefits and limitations

Benefits

  • Coordinates a business flow across independent ownership and databases.
  • Makes intermediate state and recovery behavior explicit.

Limitations

  • Compensations may fail or be impossible to reverse perfectly.
  • Workflow state, retries, timeout handling, and operator tooling add substantial complexity.

DECISION GUIDE

When to use it

Use: Use for multi-step, long-running workflows that span service-owned transactions.

Avoid: Avoid a saga for a short operation that fits in one service-owned database transaction.

COMMON MISTAKES

Watch out

  • Avoid a saga for a short operation that fits in one service-owned database transaction.
  • Assuming saga pattern guarantees outcomes beyond its stated scope.

BEST PRACTICES

In practice

  • Use explicit state transitions and terminal outcomes.
  • Do not introduce a saga where one local transaction is sufficient.

INTERVIEW PRACTICE

Common questions

  1. How does orchestration differ from choreography?
  2. Why is compensation not rollback?
  3. How should an uncertain participant outcome be reconciled?

SENIOR-LEVEL SCENARIO

Production thinking

Payment times out after inventory reservation. Query or deduplicate by operation ID before repeating authorization, persist saga progress, and release inventory only after a confirmed rejection or explicit expiry policy.

SUMMARY

In one minute

A saga trades global atomic rollback for durable coordination, idempotent local steps, and compensating business actions.
