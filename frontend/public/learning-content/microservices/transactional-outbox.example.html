APPLY THE IDEA

Worked example

Order creation and OrderPlaced outbox row commit together; a dispatcher later publishes the event to the broker.

  1. Use stable event IDs and schema versions.
  2. Monitor age and volume, not only dispatcher liveness.
  3. Plan cleanup, poison handling, and replay procedures.

CODE OR QUERY

Try it

await using var tx = await db.Database.BeginTransactionAsync(ct);
db.Orders.Add(order);
db.Outbox.Add(OutboxMessage.For("OrderPlaced", order.Id));
await db.SaveChangesAsync(ct);
await tx.CommitAsync(ct);

TRADE-OFFS

Benefits and limitations

Benefits

  • Closes the lost-publish-intent gap without a distributed commit.
  • Supports polling or CDC and lets the business transaction remain local.

Limitations

  • Adds dispatcher, storage, cleanup, and backlog operations.
  • A crash after publish but before marking completion can produce duplicate delivery.

DECISION GUIDE

When to use it

Use: Use when database state and broker publication intent must stay consistent.

Avoid: Avoid describing the pattern as exactly-once delivery or adding it where no event consistency requirement exists.

COMMON MISTAKES

Watch out

  • Avoid describing the pattern as exactly-once delivery or adding it where no event consistency requirement exists.
  • Assuming transactional outbox guarantees outcomes beyond its stated scope.

BEST PRACTICES

In practice

  • Keep the outbox write in the same database transaction as the business mutation.
  • Make consumers idempotent even if the publisher tracks sent state.

INTERVIEW PRACTICE

Common questions

  1. What dual-write failure does the outbox prevent?
  2. Why can the dispatcher publish twice?
  3. How does CDC differ from polling?

SENIOR-LEVEL SCENARIO

Production thinking

A broker outage leaves committed events pending. Alert on oldest-record age and backlog, resume dispatch, and verify replay cannot duplicate a payment or notification.

SUMMARY

In one minute

The outbox converts a dangerous dual write into durable intent plus at-least-once dispatch and idempotent consumption.
