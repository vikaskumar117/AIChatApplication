APPLY THE IDEA

Worked example

A provider publishes a new signing key; API instances load it from trusted metadata while still validating unexpired tokens signed by the retiring key.

  1. Issuer signs with current key
  2. API validates time and trusted key set
  3. Rotation overlaps keys and retires old key

CODE OR QUERY

Try it

options.TokenValidationParameters.ClockSkew = TimeSpan.FromMinutes(2);
// Configure trusted Authority/MetadataAddress and test key rollover;
// do not disable lifetime validation to work around clock drift.

TRADE-OFFS

Benefits and limitations

Benefits

  • Bounds credential lifetime and reduces impact window
  • Rotation supports cryptographic hygiene and incident recovery

Limitations

  • Very short validity can cause outages under clock or provider failures
  • Revocation and distributed key propagation are operationally complex

DECISION GUIDE

When to use it

Use: Choose token lifetimes based on threat, client, and usability needs; automate monitored key rollover and emergency response.

Avoid: Avoid infinite-lived tokens, unbounded clock skew, and ad hoc key changes without overlap or incident plans.

COMMON MISTAKES

Watch out

  • Disabling lifetime validation to fix an environment clock issue.
  • Assuming a rotated signing key instantly invalidates all previously issued JWTs.

BEST PRACTICES

In practice

  • Synchronize clocks and use small documented skew.
  • Exercise key rollover and emergency revocation in operational tests.

INTERVIEW PRACTICE

Common questions

  1. How is expiration different from revocation?
  2. Why can APIs accept old and new keys during rollover?
  3. What is the risk of excessive clock skew?

SENIOR-LEVEL SCENARIO

Production thinking

An old signing key is compromised; distinguish routine rollover from emergency compromise, remove trust promptly, invalidate affected sessions as appropriate, and monitor validation failures.

SUMMARY

In one minute

Expiration bounds how long a credential is accepted; rotation replaces credentials or signing keys while preserving controlled continuity.
