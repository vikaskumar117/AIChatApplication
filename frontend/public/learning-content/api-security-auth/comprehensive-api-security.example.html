APPLY THE IDEA

Worked example

A multi-tenant Orders API validates an Entra-issued access token, checks both order permission and tenant ownership, queries with parameters, limits expensive searches, and emits redacted trace-correlated audit events.

  1. Harden transport and edge
  2. Authenticate and authorize
  3. Validate, execute, observe, and respond

CODE OR QUERY

Try it

builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.Authority = configuration["Identity:Authority"];
        options.Audience = configuration["Identity:OrdersAudience"];
    });
builder.Services.AddAuthorization();
builder.Services.AddRateLimiter(options => { /* partition and bound costly routes */ });

app.UseExceptionHandler();
app.UseHttpsRedirection();
app.UseAuthentication();
app.UseAuthorization();
app.UseRateLimiter();
app.MapControllers();

TRADE-OFFS

Benefits and limitations

Benefits

  • Layered safeguards reduce single-control failure risk
  • Clear boundaries make controls auditable and testable

Limitations

  • Security requires operational ownership and continuous review
  • Misconfigured layers can cause outages or false confidence

DECISION GUIDE

When to use it

Use: Apply a threat-model-driven baseline to every API and add controls proportionate to data sensitivity, exposure, and abuse cost.

Avoid: Avoid describing an API as secure because it uses JWT, CORS, HTTPS, or a gateway alone.

COMMON MISTAKES

Watch out

  • Treating CORS as protection against direct HTTP clients.
  • Treating authentication as proof of authorization for every record.

BEST PRACTICES

In practice

  • Threat-model endpoints, identities, data flows, and failure modes.
  • Automate dependency updates, security tests, redaction checks, and incident-ready telemetry.

INTERVIEW PRACTICE

Common questions

  1. Why is CORS not an API authorization mechanism?
  2. How do authentication and resource authorization compose?
  3. Which controls reduce both data theft and resource exhaustion?

SENIOR-LEVEL SCENARIO

Production thinking

An external assessment finds cross-tenant access and unbounded search traffic; first enforce resource ownership and operation-specific permissions, then bound expensive work, add regression tests, and review telemetry for prior exposure.

SUMMARY

In one minute

API security is a layered system of transport protection, trusted identity, authorization, input and data safety, resilience, and operational response.
