APPLY THE IDEA

Worked example

A browser application obtains a fresh API token through the identity provider’s supported session and refresh-token policy rather than posting refresh tokens to an API.

  1. Client uses access token at API
  2. Access expires or nears expiry
  3. Client redeems protected refresh token at issuer

CODE OR QUERY

Try it

// Access token: Authorization: Bearer <resource access token>
// Refresh token: submit only to the configured authorization server's
// supported token endpoint; never send it to the resource API.

TRADE-OFFS

Benefits and limitations

Benefits

  • Short access-token lifetime limits routine exposure
  • Refresh rotation can detect stolen-token replay

Limitations

  • Refresh-token theft has prolonged account impact
  • Rotation and concurrent refreshes require issuer/client coordination

DECISION GUIDE

When to use it

Use: Use provider-supported refresh-token policy and secure storage; revoke sessions or token families when compromise is suspected.

Avoid: Avoid treating a refresh token like an ordinary API token or persisting it in an insecure browser location.

COMMON MISTAKES

Watch out

  • Sending a refresh token as a bearer credential to a business API.
  • Assuming a short access lifetime alone prevents refresh-token theft.

BEST PRACTICES

In practice

  • Use least-privilege access tokens, provider rotation, and revocation.
  • Design refresh concurrency and replay responses, then monitor and test them.

INTERVIEW PRACTICE

Common questions

  1. Which token is sent to the resource API?
  2. Why rotate refresh tokens?
  3. What should happen when a rotated token is reused?

SENIOR-LEVEL SCENARIO

Production thinking

Telemetry identifies reuse of a refresh token after rotation; revoke the affected token family, investigate session compromise, and verify refresh concurrency and reauthentication recovery.

SUMMARY

In one minute

Access tokens are presented to resource APIs; refresh tokens are high-value credentials used with the authorization server to obtain renewed access.
