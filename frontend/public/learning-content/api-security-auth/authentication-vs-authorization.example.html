APPLY THE IDEA

Worked example

A valid employee token authenticates the caller, but the API denies access to a payroll record outside that caller’s authorized division.

  1. Credential is presented
  2. Authentication establishes principal
  3. Authorization permits or denies requested action

CODE OR QUERY

Try it

[Authorize(Policy = "Payroll.Read")]
[HttpGet("{id:int}")]
public async Task<ActionResult<PayrollDto>> Get(int id)
{
    var record = await repository.FindAsync(id);
    if (record is null) return NotFound();
    return await authorization.AuthorizeAsync(User, record, "DivisionAccess")
        ? Ok(PayrollDto.From(record)) : Forbid();
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Clear separation makes policy and identity independently testable
  • Resource checks support least privilege

Limitations

  • Valid credentials alone do not ensure correct data isolation
  • Policy drift across endpoints can create gaps

DECISION GUIDE

When to use it

Use: Authenticate every protected request and authorize every sensitive operation and target resource.

Avoid: Avoid treating a successful login or token signature as blanket data permission.

COMMON MISTAKES

Watch out

  • Checking only that User.Identity.IsAuthenticated is true.
  • Trusting client-provided user or tenant IDs as identity evidence.

BEST PRACTICES

In practice

  • Apply default-deny policies to protected route groups.
  • Test authorization with realistic cross-tenant and role combinations.

INTERVIEW PRACTICE

Common questions

  1. What does authentication establish?
  2. When is resource-based authorization needed?
  3. What is the normal distinction between 401 and 403?

SENIOR-LEVEL SCENARIO

Production thinking

A user can retrieve another tenant’s record by changing an identifier; add resource/tenant authorization after authentication and test guessed IDs across tenants.

SUMMARY

In one minute

Authentication establishes a trusted identity; authorization decides what that identity may do to a specific operation or resource.
