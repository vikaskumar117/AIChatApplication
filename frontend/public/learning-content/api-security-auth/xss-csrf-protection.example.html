APPLY THE IDEA

Worked example

A browser app renders a comment as text, while a cookie-authenticated transfer endpoint requires a server-validated antiforgery token.

  1. Attacker-controlled content reaches browser
  2. Browser credentials or script behavior are abused
  3. Encoding, cookie, and request-origin defenses reduce risk

CODE OR QUERY

Try it

// Frontend: render untrusted text through framework interpolation/textContent, not innerHTML.
// ASP.NET Core cookie-authenticated MVC:
services.AddAntiforgery(options => options.HeaderName = "X-CSRF-TOKEN");
// Validate the token on state-changing endpoints; configure cookie policy deliberately.

TRADE-OFFS

Benefits and limitations

Benefits

  • Layered browser controls address distinct attack classes
  • Safe templating and antiforgery middleware reduce repeated mistakes

Limitations

  • Security depends on rendering context and cookie architecture
  • SameSite or CORS settings alone do not cover every browser flow

DECISION GUIDE

When to use it

Use: Use safe output encoding for all untrusted content and antiforgery controls when browsers attach authentication cookies automatically.

Avoid: Avoid treating sanitization as universal, disabling browser protections, or assuming bearer-token storage is safe from XSS.

COMMON MISTAKES

Watch out

  • Using raw HTML rendering for untrusted text.
  • Assuming SameSite or an uncredentialed CORS policy makes all state changes safe.

BEST PRACTICES

In practice

  • Use framework auto-escaping, context-aware encoding, CSP, and safe DOM APIs.
  • For cookie auth, implement and test antiforgery and origin controls for unsafe methods.

INTERVIEW PRACTICE

Common questions

  1. How does CSRF differ from XSS?
  2. Why can HttpOnly cookies help against token theft but not CSRF?
  3. Does CORS prevent CSRF?

SENIOR-LEVEL SCENARIO

Production thinking

A comment page introduces stored markup and a cookie-authenticated delete endpoint; render content as text, retain robust CSP as defense in depth, and require server-validated antiforgery protection for state changes.

SUMMARY

In one minute

XSS attacks run attacker-controlled script in a user’s browser; CSRF tricks a browser into sending an authenticated action using ambient credentials.
