APPLY THE IDEA

Worked example

A browser sends JSON with an Authorization header, so its OPTIONS preflight asks whether https://app.example may use POST and Authorization; the API separately validates the resulting bearer token.

  1. Browser evaluates cross-origin call
  2. OPTIONS preflight checks policy
  3. Allowed call proceeds; browser gates response

CODE OR QUERY

Try it

builder.Services.AddCors(options => options.AddPolicy("Frontend", policy =>
    policy.WithOrigins("https://app.example")
          .WithMethods("GET", "POST")
          .WithHeaders("Content-Type", "Authorization")));

app.UseRouting();
app.UseCors("Frontend");
app.UseAuthentication();
app.UseAuthorization();

TRADE-OFFS

Benefits and limitations

Benefits

  • Enables controlled browser cross-origin access
  • Keeps browser response exposure policy explicit

Limitations

  • Does not block direct clients or replace authorization
  • Credentialed CORS and wildcard origins are easy to misconfigure

DECISION GUIDE

When to use it

Use: Configure exact trusted origins and only required methods and headers for browser clients.

Avoid: Avoid wildcard origins with credentials and avoid claiming CORS prevents unauthorized requests.

COMMON MISTAKES

Watch out

  • Using CORS as the only defense for a sensitive endpoint.
  • Reflecting arbitrary Origin values or combining wildcard origins with credentials.

BEST PRACTICES

In practice

  • Test preflight for each required method and custom header in a real browser.
  • Keep CORS rules narrow and independently test authentication and authorization.

INTERVIEW PRACTICE

Common questions

  1. When does a browser send preflight?
  2. What can CORS not protect against?
  3. Why is wildcard origin unsafe with credentials?

SENIOR-LEVEL SCENARIO

Production thinking

A frontend engineer reports that a browser blocks a call while a command-line client succeeds; inspect OPTIONS routing and CORS headers, while separately verifying the API’s actual authorization policy.

SUMMARY

In one minute

CORS is a browser-enforced cross-origin response-sharing policy, not authentication or protection against non-browser clients.
