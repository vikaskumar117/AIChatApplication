APPLY THE IDEA

Worked example

An adapter converts a shipping provider’s pounds-and-string statuses into the application’s kilograms-and-shipment-state model.

  1. Keep vendor SDK types outside domain-facing contracts.
  2. Test mapping with real documented response variations.
  3. Preserve relevant error codes and retryability.

CODE OR QUERY

Try it

public interface ICarrier
{
    Task<ShipmentStatus> GetStatusAsync(Guid shipmentId, CancellationToken ct);
}
public sealed class CarrierAdapter(ExternalCarrierClient client) : ICarrier
{
    public async Task<ShipmentStatus> GetStatusAsync(Guid id, CancellationToken ct) =>
        Map(await client.LookupAsync(id.ToString(), ct));
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Protects domain code from vendor churn and incompatible types.
  • Creates a focused seam for testing external integration behavior.

Limitations

  • Mapping layers require maintenance as external contracts evolve.
  • An adapter can conceal important differences if it normalizes errors or units incorrectly.

DECISION GUIDE

When to use it

Use: Use at integration boundaries where interfaces or semantics do not match.

Avoid: Avoid an adapter that simply renames every method without meaningful translation.

COMMON MISTAKES

Watch out

  • Avoid an adapter that simply renames every method without meaningful translation.
  • Assuming adapter pattern guarantees outcomes beyond its stated scope.

BEST PRACTICES

In practice

  • Fail explicitly on unknown contract values.
  • Use contract tests or recorded sanitized fixtures for integrations.

INTERVIEW PRACTICE

Common questions

  1. What mismatch does an adapter resolve?
  2. Where should vendor-specific types be translated?
  3. How should an adapter represent provider errors?

SENIOR-LEVEL SCENARIO

Production thinking

The provider changes status spelling from `IN_TRANSIT` to `MOVING`. Update and test the adapter mapping; domain workflows remain independent of provider wire format.

SUMMARY

In one minute

An adapter contains integration mismatch while preserving the meaning and uncertainty of the external system.
