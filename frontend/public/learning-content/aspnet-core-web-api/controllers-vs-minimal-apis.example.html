APPLY THE IDEA

Worked example

A focused health endpoint may be concise as a Minimal API while a resource API with established MVC filters and conventions may remain controller-based.

  1. Select endpoint organization
  2. Routing binds and invokes handler
  3. Shared policies and services implement behavior

CODE OR QUERY

Try it

app.MapGet("/health", () => TypedResults.Ok(new HealthResponse("ok")))
    .WithName("Health")
    .WithSummary("Reports service health");

TRADE-OFFS

Benefits and limitations

Benefits

  • Controllers provide familiar structure and MVC extension points
  • Minimal APIs reduce ceremony for focused endpoint sets

Limitations

  • Controllers add conventions and structure that small services may not need
  • Minimal API registrations can become difficult to navigate when ungrouped

DECISION GUIDE

When to use it

Use: Choose based on API complexity, required extension points, operational tooling, and established team conventions.

Avoid: Avoid migrating solely on unmeasured performance claims or mixing styles without a clear boundary.

COMMON MISTAKES

Watch out

  • Assuming Minimal APIs cannot use filters, validation, or authorization.
  • Assuming selecting controllers automatically configures API-controller behavior.

BEST PRACTICES

In practice

  • Keep a consistent style within a coherent API surface.
  • Compare generated contracts and integration behavior when choosing or migrating.

INTERVIEW PRACTICE

Common questions

  1. Which MVC features do controllers organize?
  2. Can Minimal APIs use DI and authorization?
  3. What factors are more useful than assumptions about performance?

SENIOR-LEVEL SCENARIO

Production thinking

A small service has a few endpoints and a team accustomed to controllers; prototype both styles around the same service layer and compare testing, generated OpenAPI, and maintenance cost.

SUMMARY

In one minute

Controllers and Minimal APIs are two ASP.NET Core endpoint styles that share routing, dependency injection, authorization, and HTTP semantics.
