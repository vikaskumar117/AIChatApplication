APPLY THE IDEA

Worked example

A [Required] field missing from a JSON POST receives a 400 validation response instead of entering the create action.

  1. Bind request using API conventions
  2. Validate model and infer sources
  3. Short-circuit invalid input with 400

CODE OR QUERY

Try it

[ApiController]
[Route("api/orders")]
public sealed class OrdersController : ControllerBase
{
    [HttpPost]
    public ActionResult<OrderDto> Create(CreateOrderRequest request) =>
        CreatedAtAction(nameof(Get), new { id = 42 }, new OrderDto(42));
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Consistent model-state handling
  • Less repetitive binding and validation code
  • Useful API error conventions and metadata

Limitations

  • Inference may be surprising if a signature is ambiguous
  • Automatic 400 responses can change legacy clients’ observed behavior

DECISION GUIDE

When to use it

Use: Use [ApiController] for JSON-oriented MVC APIs with consistent automatic validation responses.

Avoid: Avoid relying on inference as undocumented magic; specify [FromRoute], [FromQuery], [FromBody], or [FromServices] when clarity matters.

COMMON MISTAKES

Watch out

  • Treating syntactically valid input as valid business data.
  • Returning an ad hoc 200 response for invalid model state.

BEST PRACTICES

In practice

  • Use request DTOs with explicit constraints and stable validation errors.
  • Exercise invalid JSON, missing fields, and invalid annotation values in HTTP tests.

INTERVIEW PRACTICE

Common questions

  1. What happens to an invalid model state by default?
  2. How are parameter binding sources inferred?
  3. How can a team make binding intent explicit?

SENIOR-LEVEL SCENARIO

Production thinking

An API receives a scalar parameter from an unexpected source after adding a service dependency; make the source explicit and contract-test binding and validation errors.

SUMMARY

In one minute

[ApiController] opts MVC controllers into conventions that make API binding and client-error behavior more predictable.
