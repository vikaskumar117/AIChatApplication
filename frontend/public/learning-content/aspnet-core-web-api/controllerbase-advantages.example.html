APPLY THE IDEA

Worked example

A ProductsController returns 201 with a Location header after creating a product, rather than hand-writing status and JSON response code.

  1. Route selects API action
  2. ControllerBase binds and invokes
  3. Action result becomes HTTP response

CODE OR QUERY

Try it

 [ApiController]
[Route("api/products")]
public sealed class ProductsController(IProductService products) : ControllerBase
{
    [HttpGet("{id:int}")]
    public async Task<ActionResult<ProductDto>> Get(int id, CancellationToken ct)
    {
        var product = await products.FindAsync(id, ct);
        return product is null ? NotFound() : Ok(product);
    }
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Focused API surface without Razor view support
  • Convenient HTTP results and MVC integration
  • Works with filters, formatters, binding, and DI

Limitations

  • Still couples endpoint code to MVC abstractions
  • Helpers do not enforce good status semantics automatically

DECISION GUIDE

When to use it

Use: Use ControllerBase for attribute-routed MVC controllers that return JSON, files, or other HTTP results.

Avoid: Avoid manually returning 200 for missing resources or exposing persistence entities simply because a helper makes it convenient.

COMMON MISTAKES

Watch out

  • Assuming inheriting ControllerBase automatically applies [ApiController].
  • Returning Ok(null) for a resource that does not exist.

BEST PRACTICES

In practice

  • Use explicit route and verb attributes and typed response contracts.
  • Inject application services and pass cancellation through asynchronous work.

INTERVIEW PRACTICE

Common questions

  1. Which API response helpers does ControllerBase provide?
  2. Why is it preferable to Controller for a JSON API?
  3. When should an action use ActionResult<T>?

SENIOR-LEVEL SCENARIO

Production thinking

Standardize several resource controllers so create, missing-resource, and validation responses consistently use CreatedAtAction, NotFound, and validation results while preserving service boundaries.

SUMMARY

In one minute

ControllerBase gives API controllers MVC request, binding, validation, and response helpers without the view-rendering features of Controller.
