APPLY THE IDEA

Worked example

An import pipeline normalizes a human-entered phrase for a coding exercise. The implementation below intentionally collapses repeated whitespace; preserve original separators instead if formatting is meaningful.

  1. Split "learn C# every day" into four words.
  2. Reverse the array, not each word.
  3. Join with one space to form "day every C# learn".

CODE OR QUERY

Try it

string ReverseWords(string sentence)
{
    string[] words = sentence.Split(
        ' ',
        StringSplitOptions.RemoveEmptyEntries);

    Array.Reverse(words);
    return string.Join(' ', words);
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Short and easy to explain
  • Behavior for repeated spaces is explicit

Limitations

  • Creates token and output buffers
  • Does not preserve tabs, newlines, or original spacing

DECISION GUIDE

When to use it

Use: Use when normalized single-space output is acceptable.

Avoid: Avoid when exact whitespace, quoted phrases, punctuation rules, or locale-specific tokenization must be preserved.

COMMON MISTAKES

Watch out

  • Reversing the full string reverses letters too.
  • Using Split without deciding how to handle repeated whitespace changes the output.

BEST PRACTICES

In practice

  • Write down token and whitespace rules before coding.
  • Test empty input, repeated spaces, and punctuation according to the contract.

INTERVIEW PRACTICE

Common questions

  1. How is this different from reversing every character?
  2. What happens to repeated spaces?
  3. How would you preserve the original whitespace?

SENIOR-LEVEL SCENARIO

Production thinking

A data-cleaning requirement says words must be reordered but line breaks and punctuation must remain unchanged. The simple Split implementation is insufficient; capture separators or use a tokenizer that models the actual text format.

SUMMARY

In one minute

Tokenize, reverse the token sequence, and join; choose normalization only when the requirements allow it.
