APPLY THE IDEA

Worked example

A validation tool reports the longest unique segment of a bounded input string. For user-perceived Unicode characters, replace char indexing with text-element tokens while preserving the same sliding-window invariant.

  1. Read a, b, c: the window is "abc", best = 3.
  2. Read the next a; its old index is inside the window.
  3. Move start past the old a; window becomes "bca".
  4. Continue; no later window exceeds length 3.

CODE OR QUERY

Try it

int LongestUniqueLength(string value)
{
    var lastSeen = new Dictionary<char, int>();
    int windowStart = 0;
    int best = 0;

    for (int index = 0; index < value.Length; index++)
    {
        char current = value[index];
        if (lastSeen.TryGetValue(current, out int previous) &&
            previous >= windowStart)
        {
            windowStart = previous + 1;
        }

        lastSeen[current] = index;
        best = Math.Max(best, index - windowStart + 1);
    }

    return best;
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Expected O(n) time without checking every substring
  • Stores only last-seen positions

Limitations

  • Uses O(k) memory
  • The definition of a character affects indexing and correctness

DECISION GUIDE

When to use it

Use: Use for contiguous-substring uniqueness under a clearly defined character model.

Avoid: Avoid a char-based implementation when the requirement is based on grapheme clusters or when input size is unbounded without limits.

COMMON MISTAKES

Watch out

  • Setting start to previous + 1 even when previous is before the current window moves it backward.
  • Using indexOf on every suffix can make the solution quadratic.
  • Confusing substring (contiguous) with subsequence (can skip characters).

BEST PRACTICES

In practice

  • Test repeated runs such as "bbbbb", all-unique input, and "abba".
  • Use the exact character model required by the product.
  • Bound input length when processing user-controlled text.

INTERVIEW PRACTICE

Common questions

  1. Why is this a sliding window?
  2. Why must the previous index be inside the current window?
  3. What is the time complexity?
  4. How does the algorithm differ for a subsequence?

SENIOR-LEVEL SCENARIO

Production thinking

A request validator scans arbitrarily large submitted text for a longest unique segment. Apply a request-size limit and consider Unicode text elements; otherwise, memory and CPU cost grow with attacker-controlled input.

SUMMARY

In one minute

A last-seen map and monotonic window boundary find the longest unique contiguous substring in expected linear time.
