APPLY THE IDEA

Worked example

A streaming import reports the first unique character in a short identifier. This batch solution is easy to reason about; a true unbounded stream needs a different data structure and expiration policy.

  1. Count all characters in "swiss".
  2. Scan from index 0: s has count 3.
  3. At index 1, w has count 1; return it.

CODE OR QUERY

Try it

char? FirstUnique(string value)
{
    var counts = new Dictionary<char, int>();
    foreach (char character in value)
        counts[character] = counts.GetValueOrDefault(character) + 1;

    foreach (char character in value)
        if (counts[character] == 1)
            return character;

    return null;
}

TRADE-OFFS

Benefits and limitations

Benefits

  • Two linear passes are easy to verify
  • Preserves the original first-occurrence order

Limitations

  • Uses O(k) memory
  • A character result may be ambiguous when duplicate symbols look identical in logs

DECISION GUIDE

When to use it

Use: Use for a bounded input string and return a character or index as required.

Avoid: Avoid assuming a two-pass in-memory solution works for an infinite stream or privacy-sensitive identifier.

COMMON MISTAKES

Watch out

  • Returning any character with count one can miss the first one.
  • Using only a HashSet cannot distinguish one occurrence from multiple occurrences.
  • Ignoring input limits can permit avoidable memory and CPU use.

BEST PRACTICES

In practice

  • Return an index when callers need an unambiguous location.
  • Test empty input and all-repeating input.
  • Bound untrusted input before allocating frequency state.

INTERVIEW PRACTICE

Common questions

  1. Why is a set not enough?
  2. Why do we scan the original string a second time?
  3. What should be returned if every character repeats?
  4. How would the algorithm change for a stream?

SENIOR-LEVEL SCENARIO

Production thinking

An ingestion service must flag the first unique symbol in an oversized untrusted field. Enforce a maximum input length before counting, return an index if duplicate visual characters are ambiguous, and avoid logging the complete input.

SUMMARY

In one minute

Frequency counts answer how often; a second ordered scan answers which unique character comes first.
